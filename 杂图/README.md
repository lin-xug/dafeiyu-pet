# 表情包目录

把你的表情包（`.png` / `.jpg` / `.gif` / `.webp`）丢进来，机器人就会用它们。

两种打标方式，可以混用：

1. **文件名即标签**：`高兴.png` → 标签「高兴」
2. **显式映射**：编辑 `tags.json`，一个标签可以挂多张

```json
{
  "高兴": ["高兴.png", "qq_1116c45b3c.png"],
  "无语": ["qq_92f8cb15c7.png"]
}
```

模型会在回复里写 `[[表情:高兴]]`，程序按标签找图、压缩后发出去。
标签不存在就跳过并写日志，不会报错。

> 本目录下的图片**默认不进 git**（`.gitignore` 里排除了），
> 免得把别人的表情包或带隐私的图一起提交上去。
